# DigiLocker Prototype

A front-end-only React + Vite recreation of a DigiLocker app UI prototype, originally mocked up in Claude Design. Splash, Home, Search, Issued Documents, Menu, and Profile screens, wired together with the same animations and interactions as the source prototype.

This is a UI mockup: all data is static/mocked, and all officially-branded assets (app logo, government emblem, issuer logos, UMANG artwork, profile photo, utility icons) are left as labeled placeholders rather than real trademarked art.

## Develop

```
npm install
npm run dev
```

## Build

```
npm run build
```

## Deploy

Pushing to `main` builds the app and publishes it to GitHub Pages via `.github/workflows/deploy.yml`.
